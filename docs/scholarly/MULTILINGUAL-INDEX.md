# Multilingual index sort/display contract

Index sorting and index display are separate editorial decisions. `\\PSEIndexTerm{sort-key}{display-form}` records an explicit sort key while preserving a scholarly display form, including non-Latin scripts.

PSE does not transliterate or normalize index terms automatically. Those decisions are title-owned editorial data. This avoids silently changing Greek, diacritics, names, or language-specific collation practices.
