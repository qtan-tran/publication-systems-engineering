# Archival & Citation Readiness

PSE already includes `CITATION.cff`. current release treats archival identifiers as release metadata, not something to invent before a public repository exists.

Before the first public licensed beta:

1. create the canonical GitHub repository;
2. verify author spelling and project title in `CITATION.cff`;
3. create the first legally authorised tagged release;
4. connect an archival service/DOI provider if desired;
5. add the DOI only after it actually exists;
6. archive the exact release artifact/checksums and release manifest;
7. update README citation instructions without inventing identifiers.

No DOI is claimed in current release.
