# Profile demo gallery

PSE ships finished demonstration books so you can judge the result before learning the framework.

Each example uses **synthetic content only** and follows the normal public PSE build path. Open a PDF first; if the publication type looks close to your project, follow the corresponding demo README to reproduce it or create a private project with the same profile.

## Fastest path for a non-technical evaluator

1. Open two or three PDFs above.
2. Read [Choose a profile](CHOOSE-A-PROFILE.md).
3. Install PSE from the checked-out candidate.
4. Create a private synthetic test project before moving any real manuscript into the workflow.
5. Follow [Beginner quick start](BEGINNER-QUICK-START.md).

The committed PDFs are intentional showcase artefacts, not build debris. Regression checks require a source project, README and canonical PDF for every generator-supported profile.
