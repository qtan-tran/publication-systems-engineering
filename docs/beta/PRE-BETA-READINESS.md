3. **Live candidate CI — BLOCKER for public cross-platform claims.** The candidate commit must pass the repository's Windows/macOS/Linux GitHub workflows.
4. **Commercial licensing contact — BLOCKER.** Publish a real inquiry channel without inventing placeholder contact details.
