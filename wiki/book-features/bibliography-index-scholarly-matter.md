# Bibliography, index, and scholarly matter

Bibliographies, indexes, and scholarly front/back matter are reusable publication features. PSE does not make them properties of a single “academic” profile.

## Bibliography

The bibliography module provides bibliography and citation capability.

| Profile | Policy | Starter default |
| --- | --- | --- |
| [Academic Monograph](../profiles/academic-monograph.md) | not declared | — |
| [Basic Book](../profiles/basic-book.md) | not declared | — |
| [Bilingual Edition](../profiles/bilingual-edition.md) | not declared | — |
| [Critical Edition](../profiles/critical-edition.md) | required | on |
| [Drama](../profiles/drama.md) | not declared | — |
| [Edited Collection](../profiles/edited-collection.md) | not declared | — |
| [Literary Fiction](../profiles/literary-fiction.md) | not declared | — |
| [Poetry](../profiles/poetry.md) | not declared | — |
| [Scholarly Edition](../profiles/scholarly-edition.md) | required | on |

Critical Edition and Scholarly Edition currently require bibliography in their starter policy. Other profiles can have bibliographic needs, but where no manifest policy is declared the handbook does not invent one.

## Index

The index module provides a one-column index with explicit sort/display support.

| Profile | Policy | Starter default |
| --- | --- | --- |
| [Academic Monograph](../profiles/academic-monograph.md) | recommended | on |
| [Basic Book](../profiles/basic-book.md) | recommended | on |
| [Bilingual Edition](../profiles/bilingual-edition.md) | recommended | on |
| [Critical Edition](../profiles/critical-edition.md) | recommended | on |
| [Drama](../profiles/drama.md) | recommended | on |
| [Edited Collection](../profiles/edited-collection.md) | recommended | on |
| [Literary Fiction](../profiles/literary-fiction.md) | discouraged | off |
| [Poetry](../profiles/poetry.md) | optional | off |
| [Scholarly Edition](../profiles/scholarly-edition.md) | recommended | on |

Most prose and scholarly profiles recommend an index, while Literary Fiction discourages it as a starter convention and Poetry leaves it optional.

## Editorial boundary

PSE can provide structures and deterministic production behavior, but it does not decide what belongs in a bibliography, whether an index term is intellectually appropriate, or whether a scholarly introduction is substantively adequate. Those remain editorial decisions.
