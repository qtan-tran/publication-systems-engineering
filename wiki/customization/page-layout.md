# Page layout and the PSE grid

PSE treats a book page as a planned set of regions rather than a text box that expands whenever a feature needs more room. The main text, binding-side gutter, outside margin, running-head area, footer area, and space that may later be reserved for scholarly apparatus are therefore part of one page-grid system.

Different book profiles use different proportions. A critical edition, for example, normally needs a more deliberate outer margin than a general book. PSE keeps those choices in the profile so ordinary users do not need to calculate page geometry themselves.

In PSE 1.35 this grid is infrastructure: it standardizes page regions while preserving the existing visual baselines. Margin notes and other side material are planned for later phases.

For most projects, choose the correct profile and leave its grid unchanged. A detailed non-technical layout customization guide will be written after margin objects and the integrated presentation system stabilize.
