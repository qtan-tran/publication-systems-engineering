# Typography

PSE separates **what text means** from **how that text looks**. A chapter title, a running head, an abstract label, and apparatus text can therefore use different typographic roles without changing manuscript semantics.

In PSE 1.34 the framework defines reusable roles for body text, display text, chapter titles, section headings, metadata, running heads, captions, and apparatus. Each book profile supplies appropriate defaults.

For ordinary projects, you do not need to understand the underlying TeX commands. Choose a profile first and keep its typography unless the publication has a clear reason to change it. Project-specific overrides belong in `config/pse-local.tex`.

A detailed non-technical customization guide is planned after the page architecture and presentation system stabilize.
