# Beginner Handbook

This handbook is the shortest supported path from a PSE checkout to a checked PDF. It is written for editors, researchers, translators, and small publishing teams; you do **not** need to understand the framework internals first.

By the end, you will have created a private synthetic project, edited its metadata and content, built `build/book.pdf`, and run PSE's project checks.

## The path

1. [Install and check PSE](install.md).
2. [Choose a book profile](choose-a-profile.md).
3. [Create your first project](create-a-project.md).
4. [Understand the project folder](project-folder.md).
5. [Replace the starter content](edit-your-book.md).
6. [Build and check the PDF](build-and-check.md).
7. If something fails, use [First troubleshooting](troubleshooting.md).
8. When the working build is sound, read [Where to go next](next-steps.md).

!!! warning "Start with synthetic content"
    First prove that the toolchain works on a generated starter. Do not diagnose a new installation using an unpublished manuscript. Keep real manuscripts and assets in private storage under your control.

A normal working build is not a publication release. Proof and release workflows come later.
