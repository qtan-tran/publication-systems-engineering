# What is PSE?

PSE provides a repeatable way to turn structured book source into publication outputs. A **profile** supplies sensible defaults for a kind of book; reusable **features** supply capabilities such as an index, contributor metadata, parallel text, verse structure, or critical apparatus.

You normally work with the book project rather than the framework internals. If you are new to PSE, continue with the [Beginner Handbook](index.md), which takes you from installation to a checked first PDF without requiring framework-development knowledge.
