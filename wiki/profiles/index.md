# Book profiles

PSE ships **six** supported presentation profiles. A profile controls publication presentation; semantic modules provide reusable content structures.

| Profile | Primary purpose |
| --- | --- |
| [Academic Monograph](academic-monograph.md) | Structured scholarly or general nonfiction prose |
| [Bilingual Edition](bilingual-edition.md) | Source/target aligned text |
| [Critical Edition](critical-edition.md) | Annotated or critically edited source text |
| [Drama](drama.md) | Dramatic dialogue and stage directions |
| [Edited Collection](edited-collection.md) | Multi-contributor publication units |
| [Literary Fiction](literary-fiction.md) | Reading-oriented narrative prose |

**Scholarly editions do not always constitute critical editions.** Here `critical-edition` is the unified *presentation profile*, not a claim about the scholarly method of every title produced with it. Poetry is a semantic capability (`verse-structure`), not a dedicated supported profile.
