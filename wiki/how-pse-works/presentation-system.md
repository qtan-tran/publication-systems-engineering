# The PSE presentation system

PSE keeps a distinction between **what your book contains** and **how that material looks on the page**. A contributor, chapter, verse line, locator, translation alignment, or apparatus note keeps its semantic identity even when presentation changes.

From PSE 1.40, every book profile has an explicit presentation descriptor. It records how that profile combines hierarchy, chapter-level metadata, typography and page grid, side material, apparatus, locators, and parallel text. This gives PSE one coherent presentation layer without turning visual choices into manuscript semantics.

For example, a critical edition can declare a compact hierarchy, asymmetric scholarly grid, outer-margin material, visible primary locators, and multi-stream apparatus. A literary-fiction profile can instead keep narrative flow primary and defer specialist scholarly furniture. Both still use the same framework boundaries.
