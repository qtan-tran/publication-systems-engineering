# Drama demo

**Best for:** plays and dramatic texts.

A play-oriented presentation with cast list, speakers, stage directions, acts/scenes, and dramatic locators.

## What to look for

Look for cast handling, speaker distinction, stage directions, and stable dramatic line locators.

- [Open the finished demo PDF](output/drama-demo.pdf)
- Source project: [`source/`](source/)

To rebuild this example from the repository root:

```text
python scripts/examples/build_profile_demos.py drama
```

To create a new private project with the same profile:

```text
pse new /path/to/private-projects --profile drama
```

The demo uses synthetic content only and includes the standard PSE publication-page attribution.

**Index policy:** recommended and enabled by default for this profile.
