# Literary Fiction demo

**Best for:** novels and reading-oriented prose.

A restrained reading-oriented layout with quieter chapter openings.

## What to look for

Look for the restrained chapter opening and uninterrupted reading measure rather than dense scholarly furniture.

- [Open the finished demo PDF](output/literary-fiction-demo.pdf)
- Source project: [`source/`](source/)

To rebuild this example from the repository root:

```text
python scripts/examples/build_profile_demos.py literary-fiction
```

To create a new private project with the same profile:

```text
pse new /path/to/private-projects --profile literary-fiction
```

The demo uses synthetic content only and includes the standard PSE publication-page attribution.

**Index policy:** discouraged by default for ordinary literary-fiction reading editions.
