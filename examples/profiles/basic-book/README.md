# Basic Book demo

**Best for:** general prose books.

A neutral book baseline with chapters, sections, running heads, and footnotes.

## What to look for

Look for the neutral chapter hierarchy, running-page rhythm, quotation, and footnote treatment.

- [Open the finished demo PDF](output/basic-book-demo.pdf)
- Source project: [`source/`](source/)

To rebuild this example from the repository root:

```text
python scripts/examples/build_profile_demos.py basic-book
```

To create a new private project with the same profile:

```text
pse new /path/to/private-projects --profile basic-book
```

The demo uses synthetic content only and includes the standard PSE publication-page attribution.

**Index policy:** recommended and enabled by default for this profile.
