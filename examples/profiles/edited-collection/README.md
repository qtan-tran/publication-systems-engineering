# Edited Collection demo

**Best for:** multi-author edited volumes.

A chapter-oriented edited-volume profile with reusable contributor identity and chapter-level contributor credits.

## What to look for

Look for chapter-level contributor credits and the same contributor taking a different role in another publication unit.

- [Open the finished demo PDF](output/edited-collection-demo.pdf)
- Source project: [`source/`](source/)

To rebuild this example from the repository root:

```text
python scripts/examples/build_profile_demos.py edited-collection
```

To create a new private project with the same profile:

```text
pse new /path/to/private-projects --profile edited-collection
```

The demo uses synthetic content only and includes the standard PSE publication-page attribution.

**Index policy:** recommended and enabled by default for this profile.
