# Poetry demo

**Best for:** poetry collections.

A verse presentation with stable stanza/line identity, stanza spacing, indentation, long-line continuation, and optional display numbering.

## What to look for

Look for stanza spacing, optional line numbers, and a long wrapped line that remains one semantic verse line.

- [Open the finished demo PDF](output/poetry-demo.pdf)
- Source project: [`source/`](source/)

To rebuild this example from the repository root:

```text
python scripts/examples/build_profile_demos.py poetry
```

To create a new private project with the same profile:

```text
pse new /path/to/private-projects --profile poetry
```

The demo uses synthetic content only and includes the standard PSE publication-page attribution.

**Index policy:** optional; activate it for larger collections or editions that need thematic/name navigation.
